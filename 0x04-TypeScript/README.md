# TypeScript Projects

This repository contains TypeScript learning projects covering interfaces, classes, type checking, and advanced TypeScript features.

## Project Structure

- `task_0/` - Basic interfaces and DOM manipulation
- `task_1/` - Advanced interfaces with readonly, optional properties, and index signatures
- `task_2/` - Classes, type predicates, and string literal types
- `task_3/` - Ambient declarations and third-party library integration
- `task_4/` - Namespaces and declaration merging
- `task_5/` - Brand convention and nominal typing

## Technologies Used

- TypeScript
- Webpack
- ESLint
- Node.js

## Getting Started

Each task directory contains its own setup:

```bash
cd task_0
npm install
npm run build
npm run dev
